README.md
# AI-Powered Letter of Credit (LC) Validation System

This project uses a Retrieval-Augmented Generation (RAG) pipeline and an AI agent system built with LangGraph to automatically validate a Letter of Credit against UCP 600 and ISBP 745 rules.

## How to Run

1.  **Create a Project Directory:**
    ```bash
    mkdir lc_validation_project
    cd lc_validation_project
    ```

2.  **Set up a Python Environment:**
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows, use `venv\Scripts\activate`
    ```

3.  **Install Dependencies:**
    Save the `requirements.txt` content into a file and run:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Set OpenAI API Key:**
    You must have an OpenAI API key to run this project. Set it as an environment variable for security.
    ```bash
    export OPENAI_API_KEY='your-super-secret-key'
    ```

5.  **Create Project Files:**
    -   Save the main Python code as `main.py`.
    -   Save the CSV content as `mappings.csv`.
    -   Create placeholder text files for the LC, UCP 600, and ISBP 745. You can use the provided `sampleLC.txt` or your own. For UCP 600 and ISBP 745, you will need to provide the full text for accurate validation. The script includes tiny placeholders to be runnable out-of-the-box.
        - `sampleLC.txt`
        - `UCP600.txt`
        - `ISBP745.txt`

6.  **Run the Application:**
    Execute the main script from your terminal:
    ```bash
    python main.py
    ```

The script will first create a local ChromaDB vector store (`lc_chroma_db` directory) from the UCP and ISBP texts. Then, it will run the validation agents and print a final report to the console.
